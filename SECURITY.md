# Seguridad de la plantilla

## Nunca subir al repositorio público

- Contraseñas
- Tokens de acceso
- API keys privadas
- Credenciales de servicios
- Datos bancarios
- Documentos de identidad
- Información privada de clientes

## WhatsApp

El número de WhatsApp de atención no debe tratarse como una contraseña. En un catálogo estático, el navegador necesita conocer el destino para abrir WhatsApp. Si se requiere ocultarlo realmente, hay que implementar un backend/proxy.

## Para cada cliente

1. Crear un repositorio independiente.
2. Personalizar logo, nombre, productos y precios.
3. Usar solamente datos comerciales que el cliente quiera publicar.
4. Mantener secretos fuera del repositorio público.
5. Revisar el historial antes de entregar el proyecto.
6. Transferir la propiedad del repositorio al cliente cuando corresponda.
