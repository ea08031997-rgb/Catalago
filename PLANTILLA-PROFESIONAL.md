# Plantilla profesional de catálogo online

Esta rama es una copia de trabajo de la versión estable del catálogo y sirve como base reutilizable para nuevos clientes.

## Incluye

- Catálogo responsive
- Buscador y categorías
- Productos y precios
- Carrito persistente
- Cantidades y subtotales
- Favoritos
- Pedido estructurado por WhatsApp
- QR del catálogo
- PWA / caché
- Base de configuración para clientes
- Reglas de seguridad para evitar secretos en Git

## Cómo usarla para un cliente

1. Crear un repositorio independiente para el cliente.
2. Copiar esta base.
3. Sustituir logo, nombre, colores, productos, fotos, precios y categorías.
4. Configurar el WhatsApp comercial del cliente.
5. Revisar que no haya datos del cliente anterior.
6. Publicar GitHub Pages.
7. Probar carrito, pedido, QR y versión móvil.
8. Entregar la propiedad del repositorio al cliente cuando corresponda.

## Regla fundamental

No reutilizar directamente datos personales o comerciales de otro cliente. La plantilla contiene la estructura y funcionalidad; cada cliente debe recibir su propia configuración y repositorio.
