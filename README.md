# Plantilla profesional de catálogo online

Base reutilizable para crear catálogos de clientes con diseño responsive, búsqueda, filtros, favoritos, carrito persistente, pedido estructurado por WhatsApp, QR y PWA.

## Configuración rápida

1. Duplica este repositorio para el cliente.
2. Edita `app.js` y completa el objeto `config`.
3. Sustituye el contenido de `products` por los productos reales del cliente.
4. Cambia `logo.svg`, imágenes y estilos de marca.
5. Actualiza `manifest.webmanifest` con el nombre comercial.
6. Activa GitHub Pages desde la rama que corresponda.
7. Prueba móvil, búsqueda, filtros, favoritos, carrito, QR y pedido de WhatsApp.

## Datos del cliente

No guardes contraseñas, tokens, API keys, documentos personales ni credenciales en este repositorio. El número de WhatsApp usado por una página estática no puede considerarse secreto: el navegador necesita conocer el destino para abrir WhatsApp.

## Entrega profesional

Cada cliente debe tener su propio repositorio y sus propios datos. No reutilices datos personales, fotos privadas, credenciales ni configuraciones de otro cliente.
